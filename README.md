# EduCentered

Smart Learning & Analytics Platform for SMK Akuntansi.

## What is included

- Teacher and student views with working navigation
- Teacher dashboard with demo class-performance analytics
- Courses Class: create courses, course codes, upload metadata for materials/RPP, class notes
- Quiz builder: AI/manual modes, question-type choices, preview, publish a quiz to a course
- Learning results: class recaps, distribution, student quiz results, manual grade entry
- RPP workflow: identity, learning model, objectives, time allocation, references, assessment, media, preview, Word/PDF choice
- Student dashboard with semester averages and red low scores under KKM 75
- My Courses, joining by code, course materials and published quizzes
- Student quiz demonstration and score history
- AI consultation UI
- Student feedback form and teacher feedback recap/filtering

## Important prototype limits

This repository is a front-end prototype. Data is stored in browser memory/state and resets on refresh. File upload currently stores document metadata only; it does not upload binary files. AI content is a demonstration, not generated by Gemini. Word/PDF selection currently prepares/copies text and does not create a downloadable document. Authentication, permissions, database persistence, storage, real AI, and document generation must be implemented before production use.

## Run locally

Requirements: Node.js 20 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to GitHub and Vercel

1. Create a GitHub repository.
2. Upload/extract the contents of this folder into the repository root (not a nested second `EduCentered` folder if you can avoid it).
3. Commit and push.
4. In Vercel, choose **Add New → Project**, import the GitHub repository, then deploy.
5. To update the site, push commits to the connected branch.

## AI secret

Copy `.env.example` to `.env.local` for local work. Put provider secrets only in server-side environment variables. Never use `NEXT_PUBLIC_GEMINI_API_KEY` or commit `.env.local`.

## Recommended production architecture

- Next.js App Router
- Supabase Auth + PostgreSQL for users, courses, enrollments, quizzes, quiz_results, manual_grades, feedback, and RPP records
- Supabase Storage for teacher-uploaded materials and RPP documents
- Server-side AI route for Gemini
- Server-side Word/PDF generation
- Role-based authorization and private file access
